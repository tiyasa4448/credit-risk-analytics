Dictionaries
1. 
What will my_dict = {'a': 1, 'b': 2}; my_dict['c'] return if 'c' is not a key in my_dict?
• A) None
• B) KeyError
• C) 0
• D) c
• Answer: B) KeyError
2. 
Which method is used to get a default value if a key does not exist in a dictionary?
• A) get()
• B) pop()
• C) items()
• D) keys()
• Answer: A) get()
 
Tuples
1. 
What is the difference between a list and a tuple in Python?
• A) Lists are immutable, but tuples are mutable
• B) Tuples are immutable, but lists are mutable
• C) Lists and tuples are both mutable
• D) Lists and tuples are both immutable
• Answer: B) Tuples are immutable, but lists are mutable
2. 
What will happen if you try to modify an element of a tuple?
• A) The value will be changed
• B) Python will allow modification if it's an integer
• C) A TypeError will be raised
• D) The tuple will convert into a list automatically
• Answer: C) A TypeError will be raised
 
Regular Expressions
1. 
What does the regular expression pattern \d+ match?
• A) A single digit
• B) One or more digits
• C) Any character
• D) A whitespace character
• Answer: B) One or more digits
2. 
What is the purpose of the re.search() function in Python?
• A) To replace text using regular expressions
• B) To split a string based on a pattern
• C) To search for a match anywhere in the string
• D) To return a list of all matches in a string
• Answer: C) To search for a match anywhere in the string

What is the primary purpose of a class in Python?
• A) To store a collection of functions
• B) To create new primitive data types
• C) To define a blueprint for creating objects

What does the self keyword represent in a Python class?
• A) A reference to the current instance of the class
• B) A built-in function
• C) A reserved keyword for loops
