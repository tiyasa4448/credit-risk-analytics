Summary of Python Class (Topic: String Slicing)
String Slicing:
• 
Syntax: text[start:end]
• 
Examples:
• 
text[1:3] → Extracts characters from index 1 to 2.
• 
text[0:4], text[:4] → Extracts first four characters.
• 
text[0:] → Extracts the entire string starting from index 0.
• 
text[5:] → Extracts characters from index 5 to the end.
• 
text[:] → Returns the complete string.
• 
text[4:1] → Returns an empty string because start index is greater than end index.
• 
text[0:20] → Returns the string up to the length limit (ignores out-of-bound indices).
Negative Indexing with Steps:
• 
Syntax: text[start:end:step]
• 
Examples:
• 
text[-2:-7:-1] → Reverses characters from second-last to the seventh-last.
• 
text[0:10:2] → Prints alternate characters between index 0 and 10 (exclusive).
String Examples:
• 
Example with a different string:
• 
print("Qaderoon"[3:]) → Extracts characters from index 3 to the end.
• 
Using variable:
name = "Qaderoon"
print(name[3:])
Strings are Immutable:
• 
Strings cannot be modified directly using indexing.
• 
Example:
text[4] = ","  # This will raise an error
• 
Correct way to modify a string:
text = text[0:4] + "," + text[5:]
print(text)
The 'in' Operator:
• 
Checks for the presence of a substring in a string.
• 
Examples:
print('e' in text)  # True
print('a' in text)  # False
print("ome" in text)  # False
• 
Can also be used to compare numbers as strings:
• 
Examples:
print("1" in "123")  # True
print(str(1) in str(123))  # True
String Comparison:
• 
Compares two strings.
• 
Example:
print("Shyam" == "shyam")  # False
print("He" > "She")  # False
