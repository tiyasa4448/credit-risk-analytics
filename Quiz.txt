1. What does math.sqrt(16) return?
a) 8
b) 4.0
c) 16
d) 4
Correct Answer: b) 4.0
 
2. If you want to calculate the sine of a number in radians, which function would you use?
a) math.sin()
b) math.sine()
c) sin()
d) math.angle()
Correct Answer: a) math.sin()
 
3. What is the purpose of the input() function in Python?
a) To display output
b) To get data from the user
c) To print a message
d) To exit the program
Correct Answer: b) To get data from the user
 
4. What does random.randint(1, 5) return?
a) A float between 1 and 5
b) Always the number 3
c) An integer from 1 to 5 (inclusive)
d) An error unless arguments are strings
Correct Answer: c) An integer from 1 to 5 (inclusive)
 
5. Which built-in function would you use to convert a float like 3.9 to an integer?
a) float()
b) int()
c) str()
d) round()
Correct Answer: b) int()
