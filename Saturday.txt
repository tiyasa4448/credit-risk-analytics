🟩 0:00–0:10 – What is a Condition?
“In programming, a condition is a question that leads to an action only if it’s true.
Think of examples like:
• 
If it’s 6 AM, set the alarm.
• 
If you have money in your wallet, you can buy groceries.
In Python, we use the if statement to ask these questions.”

🟧 0:25–0:40 – Adding else: What if the condition is false?
python
Copy
Edit

if age >= 18:
    print("You are eligible to vote.")
else:
    print("You are not eligible to vote.")

🟨 0:40–0:50 – elif: More Than Two Options
python
Copy
Edit
temperature = int(input("Enter the temperature: "))

if temperature > 30:
    print("It’s hot today.")
elif temperature >= 20:
    print("It’s a pleasant day.")
else:
    print("It’s cold today.")
✅ Python checks top to bottom and runs the first True condition.
